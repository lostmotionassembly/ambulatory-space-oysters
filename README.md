# ambulatory-space-oysters
A wiki for an ongoing Starfinder 2e campaign. 

Click on the **Wiki** button in the toolbar above to begin (if you're viewing on a phone, it may be hidden under the **More** button). You'll need to have a passing familiarity with [Markdown](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet), a very simple syntax for text. The wiki mostly uses just links and list elements.
